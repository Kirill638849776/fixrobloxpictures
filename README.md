# 🎮 Roblox CDN Fix (Windows)

[![Platform](https://img.shields.io/badge/platform-Windows-blue)]()
[![License](https://img.shields.io/badge/license-MIT-green)]()

Ты находишься в России и картинки Roblox не грузят? Аватары, иконки, баннеры — всё пустое или «битое»? Этот скрипт для Windows чинит это за пару секунд.

---

## 📋 В чём проблема

CDN-домен Roblox `tr.rbxcdn.com` в РФ часто резолвится в недоступный IP-адрес. Из-за этого:

- 🖼️ не грузятся аватары, иконки, баннеры;
- ⏳ картинки грузятся очень долго или отображаются «битыми»;
- 🚫 часть контента в лаунчере и на сайте просто отсутствует.

Скрипт принудительно направляет запросы на рабочие IP-адреса CloudFront через файл `hosts` и сбрасывает DNS-кэш.

---

## ⚡ Быстрый старт

1. Скачай `fix_roblox.bat` из этого репозитория.
2. Запусти **двойным кликом**.
3. Подтверди запрос UAC (нужны права администратора).
4. Дождись сообщения `Готово!`.
5. Открой Roblox — картинки должны загрузиться.

> 💡 Если в браузере всё ещё пусто — очисти кэш браузера или проверь в режиме инкогнито.

---

## 🔧 Что делает скрипт

| Шаг | Действие |
|-----|----------|
| 1 | Запрашивает права администратора (авто-перезапуск через UAC) |
| 2 | Создаёт резервную копию: `hosts.bak` |
| 3 | Удаляет старые записи `tr.rbxcdn.com` (чтобы не было дублей) |
| 4 | Добавляет актуальные IP-адреса |
| 5 | Выполняет `ipconfig /flushdns` |

### Добавляемые записи

```
18.64.211.78    tr.rbxcdn.com
18.64.211.88    tr.rbxcdn.com
128.116.126.3   tr.rbxcdn.com
```

## ❓ FAQ

**IP-адреса не работают / картинки снова пропали?**
Адреса CloudFront периодически меняются. Обнови их в скрипте (блок `echo 18.64...`) или поищи актуальные на форумах/Reddit по запросу `tr.rbxcdn.com hosts`.

**Антивирус ругается на BAT?**
Это нормально для скриптов, изменяющих `hosts`. Файл открытый — можешь прочитать его целиком перед запуском.

**Это безопасно?**
Скрипт только добавляет 3 строки в `hosts` и делает бэкап. Никаких загрузок из интернета и скрытых действий. Но **всегда читай код** перед запуском от имени администратора.

**Поможет ли на macOS / Linux?**
Нет, скрипт написан под Windows. Но идея та же — можно вручную добавить те же записи в `/etc/hosts`.
